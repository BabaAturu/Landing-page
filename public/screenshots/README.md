# Screenshots Directory

Drop your app screenshot images in this folder to display them on the landing page!

Suggested file names:
- `screen1.png` - Home / Dashboard
- `screen2.png` - Courses / Features List
- `screen3.png` - Topic / Main View
- `screen4.png` - Quiz / Interactive Screen
- `screen5.png` - Profile / Account Screen

Or update the `SCREENSHOTS` array inside `src/app/page.js` with your custom image URLs/paths.
